**Основные этапы процесса**

🔧 **Установка инструментов**

Пользователь устанавливает Arduino IDE или подключается к плате Arduino через расширения VS Code, а также настраивает среду Python с библиотеками PySerial или PyFirmata для связи с микроконтроллером.

⚙️ **Проектирование устройства**

Разрабатывается схема подключения компонентов (датчиков, светодиодов и др.) к плате Arduino, пишутся скетчи на C++ (или используют готовые библиотеки) для управления этими компонентами.

✨ **Код Python**

Параллельно создаётся программа на Python, взаимодействующая с Arduino через последовательный интерфейс. Это позволяет собирать данные с датчиков или управлять исполнительными устройствами с компьютера.

🖥️ **Использование VS Code**

Visual Studio Code используется как удобная среда для написания, тестирования и отладки обоих типов кода одновременно. Пользователи работают в одном окне редактора, переключаясь между файлами Arduino и Python.

📌 **Организация файлов**

Проект структурируется: создаются отдельные директории для Arduino-кода, Python-программ, документации и других ресурсов. Файл .gitignore добавляется для исключения временных и ненужных файлов из репозитория.

🎯 **Работа с Git**

Пользователь создаёт локальный репозиторий Git, добавляет файлы своего проекта, совершает коммиты с комментариями о внесённых изменениях и связывает этот репозиторий с удалённым хранилищем на GitHub.

🗃️ **Заливка на GitHub**

Через команду git push весь проект загружается на сервер GitHub, делая его доступным другим разработчикам для просмотра, скачивания и сотрудничества.
